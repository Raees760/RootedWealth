## 🚧 Custom Features
1. Themes - Themes can be bought from the rewards page. These themes can then be used to decorate the app to your liking. To enable a theme that you've purchased, go into settings and choose the theme you would like to use and then hit "Save & Apply" and the theme will be applied to your user interface.
2. Simulated Bank Linker - turning this setting on in the settings page, will allow user to participate in gamification features. This will also create new entries to simulate how linking your app to the bank would work.
3. Coupons - Coupons can be purchase in the rewards page. This is simulated and the coupons aren't real!
4. Streaks and Achievements - These are ways to earn coins to purchase themes and coupons. For me details, see the tutorials page in app.
5. Dark Mode - Dark mode can be toggled in the settings. Note that dark mode is not compatible with custom themes.
